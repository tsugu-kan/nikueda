# 肉枝管理表

精肉の枝肉入庫を記録するスマホ向けWebアプリです。

## できること

- 入庫の登録（入庫日・品名・番号・産地・kg・単価）。金額は自動計算
- 品名のワンタップ入力ボタン（萬野和牛／豚／ホルス）
- 一覧表示（入庫日ごとにまとめて表示）
- 品名・産地・番号での検索、産地ボタンでの絞り込み
- 表示中の件数・合計kg・合計金額
- 削除（2回押しで確定）
- CSV書き出し／読み込み（バックアップ・機種変更用）
- ホーム画面に追加してアプリのように起動、オフラインでも動作

## データの保存先

データは**使っている端末のブラウザ内**に保存されます。サーバーには送られません。

- 別のスマホやPCとは共有されません
- ブラウザの履歴やサイトデータを消すと、データも消えます
- 機種変更の前に「CSV書き出し」でバックアップし、新しい端末で「CSV読み込み」してください

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作る（例：`nikueda`）
2. このフォルダの中身をすべてアップロードする
   （`index.html` `manifest.webmanifest` `sw.js` `icons/` `README.md`）
3. リポジトリの **Settings → Pages** を開く
4. **Source** を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存
5. 数分後、`https://tsugu-kan.github.io/nikueda/` で開けるようになります

## スマホのホーム画面に追加する

- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：右上の︙ →「ホーム画面に追加」または「アプリをインストール」

## 更新するとき

`index.html` を書き換えたら、`sw.js` の `VERSION`（例：`nikueda-v1` → `nikueda-v2`）も上げてください。
上げないと、スマホに古い画面が残ることがあります。

## ファイル構成

```
index.html            アプリ本体（HTML・CSS・JavaScriptを1ファイルに収録）
manifest.webmanifest  ホーム画面用の設定
sw.js                 オフライン用のキャッシュ
icons/                アプリのアイコン
```
